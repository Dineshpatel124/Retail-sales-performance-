Retail Sales Performance Dashboard is an end-to-end analysis of 1,000 retail transactions. The data was cleaned in Python, business questions were answered with SQL (including window functions like LAG and ROW_NUMBER), and results were presented in an interactive Power BI dashboard built with DAX measures. The analysis covers revenue by product category, gender and age group, monthly and quarterly trends, weekday patterns, and the impact of premium-priced items, with business recommendations based on the findings.

Built as a project during the Coding Ninjas Data Analytics course.
